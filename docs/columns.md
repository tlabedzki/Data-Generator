# Columns

Every table of the default run (`python main.py`, seed 42), generated by `scripts/make_charts.py`. Examples come from
the first row with a value, in English. Truth columns hold the answer an analysis should find; leave them out of the
analysis and use them to check it. [data-model.md](data-model.md) shows how the tables link.
